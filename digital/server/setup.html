Your private invitation service.

The script below saves wedding designs and guest replies into private Google Sheets. It verifies atelier sign-ins and each private guest link. The couple’s dashboard displays that data as a styled guest book.

  1. Create a new Google Apps Script project in your account.
  2. Copy this code into Code.gs and save.
  3. Run configureMiidear. Google asks you to authorize Sheets and external connections for your own script.
  4. Deploy a new Web app, executing as you, accessible to Anyone. The code checks administrator and private-link access on each request. The Google Sheets stay private.
  5. Copy the deployment’s web app address into Projects → Invitation service address in the builder.

Google authorization opens for the Google account deploying the script. Spreadsheet access requests go to the sheet’s owner; they do not go to guests or the website automatically.
